ESP32-S3-ZERO BUILD3.3 V LOGIC

Each wire has its own color, matching its label and Connection detail row. Select a wire label to isolate it. Different-colored GND wires still join the same common ground bus. Crossings without dots are not junctions. Verify contact pairs before powering on.

CONNECTION DETAIL

BEFORE POWER ON

Check twice. Connect once.

Set the boost to 5.0 V. Measure between VO+ and VO− before connecting the ESP32. Screen and sensor use ESP 3V3, never the boost output.

Switch OFF for USB flashing. Disconnect battery-powered output from ESP 5V before using the ESP USB-C port. Do not assume the two sources are isolated.

Keep the protection path intact. Battery negative goes to B−. Use VO− as common GND; do not add a B− to VO− bridge.

Verify mechanical contacts. With power disconnected, find the switch COM and button contact pairs using a multimeter. Button contacts must close only when pressed.
