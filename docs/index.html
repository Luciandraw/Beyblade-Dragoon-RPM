BEFORE YOU FLASH

Three steps.
One USB cable.

  1. Plug in your analyzer

    Use a data-capable USB cable. Close Arduino Serial Monitor and any other app using the device’s port.

  2. Select your device

    Confirm the checkbox, click install and choose your board’s USB port. Review and confirm the installation in the dialog.

  3. Reset & get ready

    Wait for the success message. Press RESET if needed, then let the READY screen finish refreshing before launching.

QUICK ANSWERS

Need a hand?

My board won’t connect +

Hold BOOT, briefly press RESET, then release BOOT. Select the USB port again — its number may have changed. After installation, press RESET without holding BOOT.

If the board heats up rapidly, disconnect power and check the wiring. Reflashing does not fix a short circuit.

Can I use another board? +

This image is for the Beyblade RPM build on ESP32-S3-Zero with 4 MB Flash. PSRAM is disabled in this firmware build. The installer checks the chip family, not the board model, memory configuration or wiring.

Why is the install button disabled? +

A firmware release must be available and pass its file integrity check first. Then confirm the board and data-erasure checkbox. Use a supported desktop browser over HTTPS, or localhost for a local preview.
